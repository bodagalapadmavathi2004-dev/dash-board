# 📊 Data Visualization Dashboard

A simple and interactive **Data Visualization Dashboard** built with Python and Streamlit.  
The application allows users to upload a CSV dataset, preview the data, view basic statistical information, and visualize selected columns using different chart types.

## 🚀 Features

- 📂 Upload CSV datasets
- 📄 Preview uploaded dataset
- 📊 View basic statistical information
- 📈 Generate Line Charts
- 📊 Generate Bar Charts
- 🥧 Generate Pie Charts
- 🔍 Select columns dynamically
- 💻 Simple and user-friendly interface
- ⚡ Interactive visualization using Streamlit

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **Pandas**
- **Matplotlib**
